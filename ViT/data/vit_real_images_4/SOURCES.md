# 사진 출처 및 이용 조건

확인일: 2026-11-04. 아래 조건은 scikit-image 공식 데이터 문서의 해당 사진 설명에 근거한다. 사진 파일의 이용 조건과 scikit-image 소프트웨어 라이선스는 구분한다.

사진 바이트의 기준은 [scikit-image 0.26.0 데이터 레지스트리](https://raw.githubusercontent.com/scikit-image/scikit-image/v0.26.0/src/skimage/data/_registry.py)의 SHA-256 및 고정 GitLab 커밋 URL이다. 원본 파일명은 chelsea.png, coffee.png, astronaut.png, rocket.jpg이다.

이번 준비에는 로컬 scikit-image 0.19.3에 포함된 예제 파일을 사용했으며 4개 모두 위 레지스트리와 일치했다. 저작자 이름과 사진 설명은 ImageNet 정답 라벨을 의미하지 않는다.
