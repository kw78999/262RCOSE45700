# ResNet50 PE fusion × 모드 × 배치 실험 (18 조건)

조건마다 새 프로세스 + 새 compiler 캐시, 1회차. 첫 호출 1회 → 워밍업 10 → 반복 50, 이어서 구간 분리 루프 (워밍업 5 → 50회). 빈 PE를 쓰려고 job마다 물리 PE가 다르다(표 1의 물리 PE 열); 측정 구간은 한 번에 한 job만, 나머지 프로세스는 모두 일시정지한 상태에서 잰다. BF16, `bn_folded_output_split128`, CPU fallback 끔.

**진행: 18개 중 18개 측정 완료.** 실행 경과(병렬 실행, 컨테이너 재시작 2회, 순차 마무리)는 `NOTES.md`. † = 측정 조건 주의(4절), ‡ = Eager 배치 분할 변형 포함 (분할 크기가 fusion마다 달라 같은 모델 구성의 비교가 아님).
